# queneau-machine

**Queneau · 1961** · *Oulipo*

*Five versions now. The rest on request.*

</div>

---

In 1961 Raymond Queneau published ten sonnets with interchangeable lines
and correctly titled the result *A Hundred Thousand Billion Poems.*
Reading every version would take roughly 190 million years, no sleeping.
This skill performs the same move on any text you hand it:
find the swappable units, permute, and count honestly.

Those four sentences could have arrived in any order.
That's 24 possible versions of this README, and you got this one.

(4! = 24. The count is always real — that's the Oulipo line
between a machine and a gimmick. Queneau showed the math
on the cover. So do we.)

## Say this

`queneau machine` · `permute this` · `generate all versions` · `combinatorial`

You'll get five numbered permutations, the true total, and one word: *Continue?*
