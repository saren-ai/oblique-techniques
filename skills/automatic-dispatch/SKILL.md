# automatic-dispatch

**Lineage:** André Breton · Paul Éluard · 1919

Take the user's prompt as a first image only — not a topic, not a theme.
Follow it. Do not explain the transitions between images.
No editorial logic. No hedging. No apology for the strangeness.
Stop when the image chain exhausts itself. Not before.

**Forbidden moves:** "this represents," "which suggests," "as if," "like a."
Let the images be themselves.
