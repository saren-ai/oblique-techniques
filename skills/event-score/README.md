# event-score

**Maciunas · Ono · Fluxus · 1962** · *Fluxus*

*May be impossible. Still due Friday.*

</div>

---

In 1962 Fluxus reduced composition to instruction.
La Monte Young told performers to draw a straight line and follow it.
Yoko Ono told readers to imagine the clouds dripping.
The score *was* the work. Performing it was optional.
Imagining it was not.

This skill writes those. One to four lines, imperative mood,
plain words, no title, no explanation. Like so:

```
Install a skill.
Forget which one.
Begin.
```

## Say this

`event score` · `write a fluxus piece` · `give me a score` · `write me an instruction`

Name a subject if you have one. Silence also works — it usually did.

curl -fsSL https://raw.githubusercontent.com/saren-ai/oblique-techniques/main/install.sh | bash -s -- event-score
